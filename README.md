# OmniFood – Responsive Food Delivery Landing Page

OmniFood is a responsive food delivery landing page built using HTML and CSS. The project provides information about healthy food delivery services through a clean and user-friendly design.The goal of this project is to practice HTML structure, CSS styling, Flexbox, CSS Grid, animations, and responsive web design.

### Features

* Responsive navigation bar and hero section.
* How It Works section with app download buttons.
* Cities where the service is available.
* Customer testimonials section.
* Pricing plans with sign-up buttons.
* Responsive layouts for desktop, tablet, and mobile screens.
* CSS hover effects and animations.

## Technologies Used

* HTML
* CSS
* Media Queries

## How to Run the Project

1. Download or clone the project to your computer.
2. Open the project folder in Visual Studio Code.
3. Make sure index.html, style.css, and the images folder are present.
4. Open index.html in your browser.

## Responsive Breakpoints Used

The project uses CSS media queries to adjust the layout for different screen sizes.

1. Desktop (≥1200px): full layout as grid
2. Tablet (≤834px): sections stack nicely, grid becomes 2 columns where needed
3. Mobile (≤390px): single column layout, nav collapses (hamburger OR stacked menu)


These breakpoints are used where needed for individual sections. Not every section needs every breakpoint.
